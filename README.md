# Inventory Management & Billing System

## Overview

A Python-based Inventory Management and Billing System designed
to manage products, stock, sales, customers and business reports.

## Features

### Product Management
- Add products
- View products
- Update products
- Delete products
- Search products

### Inventory
- Stock management
- Add stock
- Low-stock alerts
- Inventory reports

### Billing
- Multiple products per sale
- Quantity management
- Discount calculation
- Payment method
- Automatic stock deduction
- Profit calculation

### Sales
- Sales history
- Individual sale details
- Customer purchase history
- Transaction records

### Reports
- Today's business report
- Best-selling products
- Inventory report

## Technologies

- Python
- OOP
- Dictionaries
- Lists
- Functions
- JSON
- File Handling
- Exception Handling

## Data Storage

JSON files are used for data persistence.
